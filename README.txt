DAILY LOG - how to put it online and install it

FILES
  index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, apple-touch-icon.png
  Keep all six files together in one folder.

HOST IT (free, about 2 minutes)
  Netlify Drop: go to app.netlify.com/drop, unzip this download, then drag the whole folder in.
  Alternatives: GitHub Pages, Cloudflare Pages (any static host works).
  You get a web address that must be https (the hosts above all provide it).

INSTALL IT
  iPhone (Safari): open the address, Share, Add to Home Screen.
  Android (Chrome): open the address, menu, Install app / Add to Home screen.
  Desktop Chrome/Edge: open the address, click the install icon in the address bar.
  Mac Safari: File, Add to Dock.

YOUR DATA
  Data is stored in each browser/device separately. It does not sync.
  Use Log tab > Daily goals > Backup > "Export backup" regularly.

UPDATING TO A NEW VERSION
  1. In the OLD version: Export backup (save the .json file).
  2. Put the new version online (re-upload the folder to the same site if you can;
     that keeps the same address, so your data stays where it is).
  3. If the address changed or the data looks empty: open the new version, choose the
     .json file, pick "Import: replace everything" (or "merge with current data"), press Import.
  Merge keeps what is already there and only adds days, weights, foods and meals that are missing.
  New versions read old backups: missing newer fields just get defaults.

CAMERA / SCAN FOOD
  Needs the https address and camera permission. Barcode lookup and label reading need internet.
  Barcode data comes from Open Food Facts (community data: always check the values).
